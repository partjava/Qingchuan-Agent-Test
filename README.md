# 晴川校园办事智能体与全生命周期可靠性评估系统

全国 IT 技能大赛 · AI 赋能·智能测试创新挑战赛作品。系统结合校本规章知识库、TF-IDF、BGE 语义检索、加权 RRF、LangGraph 状态图与只读工具沙箱，实现全方位智能测试与高可靠性评估。

## 基于LangGraph的校园办事智能体

智能办事流程已接入 **LangGraph 1.2.6**，由真实的 `StateGraph` 编排 `decide → tools → decide → verify → finish` 及异常、澄清、修正分支。框架负责节点状态与条件路由，项目负责只读工具、证据核验、8次模型决策与90秒预算。普通问答与页面操作保持原样。安装依赖后按原方法启动，迁移说明和验证方法见 [LangGraph说明](docs/AGENT_LANGGRAPH.md)。

网页新增“智能办事”模式：配置云端兼容模型或本地Ollama后，由模型选择知识查询、地点查询、示意路线和时间工具，读取结果后继续执行或追问。最终回答按已取得的证据整理，工具轨迹可查看与导出。原普通问答及地图功能保留。

没有模型配置时明确提示；离线检查保留为开发验证，不能作为真实模型任务准确率。启动方法不变，详细配置、使用与验证方式见 [使用说明](docs/AGENT_V1.md)。

## 本次新增的六项 NLP 能力

1. **意图识别与证据抽取**：识别时间、金额、条件、联系方式、位置、专业等问题类型。答案从实际资料抽取，逐句附引用编号；取消代码中固定写死的时间、电话和金额。
2. **多轮对话与指代消解**：浏览器和命令行可理解“那周末呢”“那二等奖呢”等省略提问。新主题阻断旧上下文，歧义时要求补充对象，清空记录同步清空上下文。
3. **检索精排**：两路扩大召回，按 0.35/0.65 权重融合 TF-IDF 与 BGE 排名；增加专题规章候选、证据相关性排序及同节候选限制。默认使用可解释规则；可选本地交叉编码精排模型。
4. **用词归一化**：统一“计院”“学工处”等简称和“图书管”等明确错字；模糊词只给建议。借阅问题中的“老师”归一化为“教职工”。
5. **分句切块与上下文补全**：按段落、句子和三级标题切分；保留重叠、同节上下文、来源 URL 和 section_id，保护英文词和时间/小数边界。向量缓存校验完整语料和模型指纹。
6. **答案质量评测与拒答**：新增 43 道参考事实题，覆盖多轮、简称、未知事实与歧义；检查参考事实覆盖、来源编号、证据链接、数字依据及拒答。RRF 排名分数不作为回答置信度。

详见 [NLP 增强说明与验收](docs/NLP_ENHANCEMENTS.md)。这些功能都已接入 `/api/chat`，不是独立演示脚本。

## 追加改进：复合问题与 Flash 配置

支持多个对象、多个属性及并列奖学金等级分别查证，按“对象—属性—条件”解析并绑定事实；部分缺少依据时逐项说明。新增“用当前方式重新回答上一题”，修复三种检索按钮的选中状态，并明确切换对下一次提问生效。

DeepSeek 云端默认模型已更新为 **V4.1 Flash（API 名 `deepseek-flash`）**，思考开关独立设置，默认关闭；保存配置不自动测试真实 Key。说明和验证结果见 [复合问题、检索按钮与 Flash 接入](docs/COMPOSITE_AND_FLASH.md)。

## 五大人机交互与工程亮点

1. **3D 地标反向咨询 AI 闭环**：在 3D 校园沙盘中点击任意建筑，弹出的详情卡片中增设「🤖 咨询 AI」按钮，通过 `window.postMessage` 机制反向联动聊天流，实现“点击沙盘地标 -> 自动组装专业咨询问句 -> RAG 检索官方文献 -> 直出解答”的交互闭环。
2. **麦克风普通话语音识别输入 (STT)**：输入框集成原生 Web Speech API 语音听写，支持点击麦克风实时将普通话口述转化为文字并提交，提供录音呼吸波纹视觉反馈。
3. **自由分屏比例预设切换**：页面顶栏集成 `7:3`（地图优先）、`5:5`（对称平衡）、`3:7`（问答优先）三档分屏布局切换，一键自适应重绘 3D 视口，满足不同演示与阅读偏好。
4. **一键导出问答全景 Markdown 报告**：支持将交互会话中的所有轮次（含提问、意图改写、检索模式、生成耗时、AI 答复及引用的官网链接）一键导出为标准的 `.md` 附件（含课程与学号元数据），便于直接作为测试报告附录。
5. **输入框键盘历史记忆导航**：输入框支持键盘 `↑` / `↓` 方向键快速回溯上一条/下一条历史提问，极大提升演示与多轮问答测试效率。

## 启动

推荐使用已有的 Python / PyTorch 环境。依赖见 `requirements.txt`：

```powershell
python -m pip install -r requirements.txt
python main.py --web --port 8000
```

浏览器打开 `http://127.0.0.1:8000`；Windows 可双击 `start_web.bat`。命令行模式：

```powershell
python main.py --cli
```

CLI 输入 `/clear` 清空上下文，输入 `exit` 退出。浏览器中的“清空记录”也会清除问答上下文。

本地 BGE 模型位于 `models/bge-small-zh-v1.5`。切块或资料变动后首次启动会重新计算向量，后续使用缓存。实际切块数量由页面“知识库概况”动态显示。

## 演示提问

- `图书管晚上几点关门？` → 自动归一化，区分闭馆与停止借还业务。
- 接着问 `那周末呢？` → 补充上一轮图书馆主题。
- `奖学金申请什么时候截止？` → 查找申报规定，不触发选课回答。
- `晴川奖学金一等奖多少钱？`，然后 `那二等奖呢？`。
- `计院有哪些专业？`、`学工处电话是多少？`。
- `图书馆馆长手机号是什么？` → 缺乏明确依据时拒答。
- 清空记录后问 `它在哪里？` → 要求说明对象。
- `从南大门怎么去图书馆？` → 保留原有 3D 导航联动。

每条回答可展开“时间查询 / 申请条件等 · 已找到原文依据”，查看实际问句改写、用词调整及采用的原文。引用卡片保留原文弹窗与来源链接。

## 评测与自动化测试体系

本项目针对智能体在垂直业务场景中的可靠性与稳定性，构建了完整的全生命周期测试体系。

### tests/ 目录下 25 份测试脚本说明

#### 一、 智能体与 LangGraph 调度测试（Agent 专项）
专门测试多智能体决策、工具调用、状态流转和死循环熔断：
- **`test_agent_graph.py`**：测试基于 LangGraph 构建的状态机图（StateGraph），验证节点流转、条件边分支选择、独立 Token 预算以及 8 步强制递归熔断。
- **`test_agent_planner.py`**：测试智能体规划器（Planner），模拟真实 HTTP 交互，验证多步骤拆解是否合理。
- **`test_agent_plan.py`**：测试智能体长链条规划的具体执行逻辑与证据整合。
- **`test_campus_agent.py`**：智能体行为契约测试，验证智能体在面对校园办事任务时的工具调用序列。
- **`test_agent_tools_store.py`**：测试智能体工具箱（Tools）与状态存储器（Store）的数据读写与工具执行。
- **`test_agent_api.py`**：测试智能体对外暴露的后端 Web API 接口（`/api/agent/*`）。

#### 二、 混合检索与 RAG 引擎测试（Retrieval & RAG 专项）
测试双引擎检索算法、排名融合与问答管道：
- **`test_hybrid_retriever.py`**：测试 Hybrid 混合检索器，验证 TF-IDF 字面分与 BGE 语义向量分的加权融合算法（RRF/加权平均）。
- **`test_rag_pipeline.py`**：测试完整的 RAG 问答主流水线（端到端检索 $\rightarrow$ 证据筛选 $\rightarrow$ 提示词组装 $\rightarrow$ 生成）。
- **`test_composite_pipeline.py`**：测试复合问题问答流（例如同时询问两项不同业务的交叉问题）。
- **`test_canteen_location.py`**：专项测试食堂、宿舍等地理位置型问答的召回与定位精度。
- **`test_topic_coverage.py`**：测试校本规章各个主题（奖助学金、选课、毕业、图书等）的检索覆盖率。

#### 三、 意图理解、槽位抽取与证据链测试（NLU & Evidence 专项）
测试对用户错别字、倒装口语的容错以及证据片段的真实性校验：
- **`test_query_understanding.py`**：测试查询理解模块（分词、实体识别、意图分类）。
- **`test_fact_slots.py`**：测试事实槽位提取器（从非结构化文本中精准抠出电话、时间、地点、金额等硬事实字段）。
- **`test_evidence.py`**：测试证据重排序与证据段落提取，确保回答只引用高置信度官方段落。
- **`test_article_reading.py`**：测试长篇规章制度文档（如章程、条例）的细粒度段落切分与局部阅读理解。

#### 四、 接口契约与大模型客户端测试（API & Client 专项）
测试前后端数据交互协议和大模型接口适配：
- **`test_chat_schemas.py`**：基于 Pydantic 的接口契约测试（测试请求体字段校验、非法参数拦截、格式异常报错）。
- **`test_deepseek_client.py`**：测试大模型 API 客户端封装（超时重试机制、Token 统计、流式输出解析与断网模拟）。
- **`test_custom_ai_and_history.py`**：测试用户自定义大模型端点（支持切换第三方 API 或本地 Ollama）与历史记录管理。

#### 五、 底层数据加载与向量缓存测试（Data & Cache 专项）
测试离线数据处理与存储性能：
- **`test_document_loader.py`**：测试校本 Markdown/文本知识库的清洗、切分与元数据加载。
- **`test_embedding_cache.py`**：测试 BGE 向量离线缓存（`.npy` 和哈希校验），确保服务器启动时秒级加载已有向量，不重复编码。
- **`test_db_manager.py`**：测试 SQLite 本地数据库的管理（问答日志存储、反馈打标、历史会话持久化）。
- **`test_kb_display.py`**：测试前端展示的知识库文档数与语义块统计是否与底层实际加载量一致。

#### 六、 评测与断言逻辑测试（Evaluation 专项）
- **`test_answer_evaluate.py`**：测试评测脚本自身的准确性判定算法（如对比模型答案与标准答案时的 ROUGE/BLEU 评分及事实一致性打分逻辑）。

#### 七、 前端 UI 自动化测试（Node.js 端）
- **`test_chat_ui.cjs`**：使用 Node.js 针对对话界面的前端交互、气泡渲染、历史记录加载进行的自动化测试。
- **`test_agent_ui.cjs`**：针对智能体多步执行轨迹折叠面板、工具调用卡片等 UI 组件进行的渲染测试。

### 测试执行命令

```powershell
# 1. 执行全量 Python 白盒单元与回归测试（共 185 项测试用例）
python -m unittest discover -s tests -v

# 2. 执行前端交互与 UI 自动化回归测试（共 22 项测试用例）
node --test tests/test_chat_ui.cjs tests/test_agent_ui.cjs

# 3. 检索级指标评测：Hit@k、MRR、NDCG
python main.py --eval

# 4. 答案级参考事实、证据、引用、拒答和歧义评测（三种检索模式对照）
python main.py --eval-answers

# 5. 执行智能体离线决策与工具调用轨迹评测
python eval/agent_evaluate.py
```

答案评测输出 `eval/answer_eval_results.json`，题目在 `eval/answer_dataset.json`。另有12道复合/变式题 `eval/composite_dataset.json` 和 `eval/composite_eval_results.json`。检索评测输出 `eval/eval_results.json`。标准用例库见 `eval/unified_test_cases.csv`（覆盖 7 大维度 400+ 条用例）。

## 可选生成模型与精排模型

无 API Key 也能运行全部六项能力。DeepSeek API 或本地 Ollama 仍可配置；生成结果仅在可与选中原句及编号逐项核验时采用，否则回退原文抽取。资料不充分时不会调用生成模型补造事实。

如已有本地、单相关性 logit 的交叉编码模型，可设置：

```powershell
$env:RAG_RERANKER_PATH = 'D:/models/your-local-reranker'
python main.py --web
```

未配置或模型加载失败时使用规则精排，返回的 `retrieved_chunks[].details.reranker` 会标明实际方式。不自动下载精排模型。

## 主要文件

```text
core/query_understanding.py  简称与错字处理、意图和多轮问句分析
core/evidence.py             证据筛选、事实约束、规则/可选交叉编码精排
core/direct_extractor.py     基于实际证据的答案抽取
core/document_loader.py      分句、章节上下文与元数据
core/hybrid_retriever.py     加权融合、专题候选与精排
core/rag_engine.py           问答、安全、证据引用与地图编排
web/schemas.py              请求参数与会话历史约束
web/app.py                  FastAPI 服务
web/static/js/chat.js       对话、上下文、依据展示、语音及地图桥接
web/static/campus3d/        3D 校园与路径导航
main.py                    Web / CLI / 两类评测 / 爬虫入口
eval/answer_dataset.json     43 道答案级评测题
```

知识库中的事实来自项目现有本地资料；本次增强未重新核实学校政策的时效性。规则式意图识别、错字表和证据筛选有覆盖边界，资料发生变化后需要重新同步与评测。命名实体模块仍为校园词典规则识别，语音能力由浏览器支持情况决定。
